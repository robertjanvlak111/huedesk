# Bundled font

**Archivo SemiExpanded** by Omnibus-Type, under the
[SIL Open Font License 1.1](OFL.txt) (see `OFL.txt`, which must stay with
these files).

- Upstream: <https://github.com/Omnibus-Type/Archivo>

Archivo is a grotesque drawn for high legibility at interface sizes, and it
ships real width variants. The SemiExpanded cut gives Hue Desk the wide,
open feel of the Hue app without the cramped rendering a fully Expanded face
produces at widget sizes.

It is bundled rather than depended upon so the widget looks the same on every
machine, whatever fonts the user happens to have. Pick any installed font
instead in the settings app; this is only the default.
